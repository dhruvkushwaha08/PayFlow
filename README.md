# PayFlow

PayFlow is an AI-powered employee payroll automation system designed for small businesses such as cafes, restaurants, shops, and other growing organizations.

The system helps businesses manage employees, attendance, advances, bonuses, overtime, salary structures, and monthly payroll from a single platform.

## Features

- Employee management
- Employee roles and salary structures
- Attendance management
- Attendance status tracking
- Employee advances
- Performance bonuses
- Overtime management
- Automated monthly payroll calculation
- Salary slips and payroll history
- JWT-based authentication
- Role-based access control
- REST APIs using Spring Boot
- React-based frontend
- MySQL database
- Docker containerization
- Docker Compose setup
- Automated payroll calculations
